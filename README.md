# Capture The Stack Fall 2026

This event took place on November 4th, 2026.

This repository will contain all of the challenges I made for this event, including:
- Overview (what participants saw)
- Flag (in spoilers of course)
- Intended Solution (steps to get to the flag)
- Personal Thoughts (including a difficulty rating out of 10, ranging from 1.00 to an insane 10.00)

Most of my challenges spanned a couple of categories including but not limited to:

- An Introduction to CTF Flags
- Cryptography and Forensics
- HaXOR (and the storyline that comes with it)
- OSINT
- Miscellaneous
