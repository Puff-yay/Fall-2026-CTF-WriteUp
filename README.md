# Capture The Stack Fall 2026

This event took place on November 4th, 2026.

The participants were given ~90 minutes to get as many points as they can, without the use of AI.
Teams caught using AI would be disqualified.
This event contained 45 challenges and 23 of them are made by me (documented here).
Thank you both the MOS and UBSIT e-boards especially MOS President (Alyssa Gannon) and UBSIT President (Tyler Lorence) for putting this event together.

This repository will contain all of the challenges I made for this event, including:
- Overview (what participants saw, including point value)
  - Hints provided will also be in this section, under spoilers of course.
- Flag (in spoilers of course)
- Intended Solution (or at least MY intended solution)
- Personal Thoughts
  - This also includes a difficulty rating from 1 to an insane 100. No challenges I make this time around will hit a 100 but there are some that will be up there for now.
  - This section also includes some stuff that you might not know about the challenge's creation so please give this a read.

Most of my challenges spanned a couple of categories including:

- An Introduction to CTF Flags
- Cryptography and Forensics
- HaXOR (and the storyline that comes with it)
- OSINT
- Tech News
- Miscellaneous

Disclaimer: For GitHub styling purposes, some of the text will be very minimally altered to make it more pleasant to read. It will not affect the challenge in any way shape of form.
